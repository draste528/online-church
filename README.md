# Online Church

Учебный веб-сервис онлайн-церкви (каталог ритуалов, пожертвования, чат-консультации).

## Стек технологий
- **Backend:** C# (.NET / ASP.NET Core Web API) + Entity Framework Core
- **Frontend:** TypeScript + React (Vite)
- **База данных:** PostgreSQL / SQLite

## Структура репозитория
- `/backend` — Исходный код API-сервера
- `/frontend` — Клиентская часть приложения
- `/docs` — Документация, Swagger-схемы, Postman-коллекции
